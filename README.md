# Supplier Connect Hub

I need to create the wireframes for the following project for customer rainco, I am going to build a supplier evaluation and supplier portal using react, node, sql. and this is integrating with SAP B1. supplier evaluation and portal should be implemented in the same web application as two side navbar tabs supplier portal should only be access by suppliers and supplier evaluation is only access by rainco users.Supplier evaluation is for evaluating suppliers based on some criterias and portal is for supplier to view their ratings and update the purchase quotations send to them. here it is sending a link through email to supplier to register to the system. so once the supplier got the link they are registering to the system through that link. the registration form should look like this, it has header in header it has Name , Email, Phone No, Type of Business (Individual, corporate, government),Currency ,Business Registration No, Username and password and remark and there are two child tabs Contact Persons and Address Details. In Contact Persons following details should be there First name, last name, NIC, Mobile, Email, Title, Position and Address. and there can be many contact persons. in address details tab there should be Address, House no, building, street, city, country, state, zipcode. And in supplier Evaluation there should be a master called Supplier Checklist in that it needs to select Type of Business for that type it needs to add required documents , it should have a add button to add required documents when adding a row to the grid it has columns Document Code, Document Name. and when registering the supplier based on what type of business select it should supplier should upload the attachments. attachments should be a another child tab. create the wireframe for this.
